# The Reserve — Private Country Club (concept demo)

Immersive single-page concept site for a fictional private country club.

- **Design:** light editorial luxury — white `#ffffff`, ink `#111111`,
  bronze accent `#8b7355`; Founders Grotesk / Inter; letterspaced uppercase labels.
- **Interactions:** loading screen, sticky hero with staggered entrance,
  scroll-driven video progress bar, parallax divider, clip-path quote reveal,
  hover-zoom gallery, tier cards, smooth scroll.
- **Stack:** single `index.html` (inline CSS + JS). No build step.
